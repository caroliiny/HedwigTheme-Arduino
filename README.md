# Arduino – Harry Potter Theme (Hedwig’s Theme)

# Ana Caroliny Virgilio de Medeiros 
# Aretuza Raquely de Oliveira Costa

Este projeto utiliza um **Arduino Uno** para tocar a música tema de *Harry Potter (Hedwig’s Theme)* por meio de um **buzzer**, além de utilizar **LEDs** e um **display LCD** para exibição de informações.

O objetivo é demonstrar, de forma simples e didática, como o Arduino pode ser usado para **reproduzir sons**, **controlar LEDs** e **interagir com um display**, mesmo para quem não tem conhecimento prévio em hardware.

---

## 🧩 Componentes utilizados

- Arduino Uno  
- Buzzer  
- Display LCD 16x2  
- Potenciômetro (ajuste de contraste do display)  
- LEDs  
- Resistores  
- Protoboards  
- Jumpers (fios)

---

## ⚙️ Como funciona

- O Arduino executa um código contendo as notas musicais da trilha sonora de Harry Potter.
- O **buzzer** reproduz a melodia conforme os sinais enviados pelo Arduino.
- O **display LCD** exibe informações relacionadas ao projeto.
- Os **LEDs** acendem como feedback visual durante a execução da música.
- O **potenciômetro** permite ajustar o contraste do display para melhor visualização.

---

## Circuito

O circuito foi montado em protoboards, conectando:
- O display LCD ao Arduino
- O buzzer a uma porta digital
- LEDs com resistores para evitar sobrecarga
- Um potenciômetro para controle do contraste do LCD

O esquema de montagem pode ser visualizado na imagem presente neste repositório.

---

## ▶️ Como usar

1. Conecte o Arduino ao computador via USB  
2. Abra o código na **IDE do Arduino**
3. Faça o upload do código para a placa
4. O buzzer tocará automaticamente a música do Harry Potter 🎶
